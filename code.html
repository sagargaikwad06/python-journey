#018 Medium 🔥 High Frequency

What is the exact distinction between is vs == in CPython?

== checks for structural equivalence via __eq__(), whereas is asserts identity pointer equality (id(a) == id(b)).

python CPython 3.12 
# Value vs Reference comparison
a = [1, 2, 3]; b = [1, 2, 3]

print(a == b)  # True  (Value equality)
print(a is b)  # False (Memory identity: id(a) != id(b))

# Note: Small Integer Caching [-5 to 256] shares pointer
x = 256; y = 256
print(x is y)  # True (Cached internal singleton)

def fibonacci():
    """Yields fibonacci sequence indefinitely with O(1) space."""
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
